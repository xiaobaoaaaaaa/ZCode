# 展开底部输入框

桌面与 Web 的常规会话输入框在正文右上角提供「展开输入框」按钮，新草稿、已有会话和底部消息编辑态使用同一交互。Side Pane 完整视图的单行浮窗沿用紧凑布局。

默认随正文增高至 10rem。点击展开后正文占动态视口高度的一半，超出的文字在正文内滚动，工具栏留在正文下方。再次点击「收起输入框」恢复原来的自适应高度。按钮支持键盘操作，向辅助技术报告展开状态。用指针切换时保留正在编辑的选区和焦点。

```text
点击按钮 → ChatPromptEditor 切换本地展开状态 → 同一个 Lexical 正文更新高度
```

展开仅在当前输入壳实例中生效。切换高度不写草稿、不发送消息；发送和排队仍通过原有入口执行。

## 验收

在桌面与窄视口输入超过紧凑上限的长文，选中部分文字后展开。检查正文可见高度增加、选区和草稿保留、超长正文可滚动且按钮可操作。再次收起后检查高度恢复、草稿可继续编辑。用 Tab 聚焦按钮后可用空格或 Enter 切换。

# Bootstrap 测试隔离回归记录

全 CLI 在只读真实 home 沙箱下发现 23 个 bootstrap 文件失败（103 项失败）。主要原因是既有 app 装配测试未注入用户目录，默认插件播种访问真实个人 profile；沙箱阻止写入。测试现在统一通过 Vitest setup 把 `os.homedir()` mock 为每个测试文件的临时目录，结束后清理，不修改 HOME/USERPROFILE，不放开沙箱权限。

用户级命令、插件配置、保存工作流、信任记录、设备标识的夹具更新为 `.zcode-personal`；项目级 `.zcode` 保持原约定。工作流夹具改用 mock，不再改变 HOME 环境。通用 registry app 测试基座默认关闭后台记忆抽取，避免额外模型请求影响当前被测协议；专门测试仍可显式启用。历史消息编辑断言更新为更早用户轮次可编辑，保留其他投影断言。

验证命令在 `bwrap --ro-bind / /` 下，只给当前仓库及 `/tmp` 写权限，Vitest `--maxWorkers=2`。23 个原失败文件定向重跑得到 442 通过、1 个设备标识旧路径夹具失败；修正最后路径后该文件 2/2 通过。没有修改生产运行时。全 bootstrap 验证由主任务继续，不把定向结果写成全包通过。

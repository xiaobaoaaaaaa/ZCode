# ZCode Personal 3.18.2-personal.5

本版基于 3.18.2-personal.4（工作区助手研究预览），修复动态工作流恢复运行时子代理任务指令重复下发的问题。

- 恢复运行时，已收到任务指令的子代理改为沿用原指令无输入续跑：保留既有对话与工具结果，解除上一次中断，不再重复写入用户输入或触发 prompt 提交钩子。排队中尚未收到指令的子代理仍按首次派发处理。
- 同一子代理连续多问文本相同时，按持久化消息的稳定输入 ID 逐问区分，不会吞掉新任务；旧版本转录没有稳定 ID 时，按上一次完整交换的消息边界之后的原文核对交付。停止与恢复可反复多次，桌面与手机消费同一套子代理轮次事件与续跑边界。
- 定向回归：动态工作流 run service 248 项、取消回归 9 项在 Windows 通过，覆盖重复停止恢复、同文排队 ask 首次交付等新增用例。DWU-01 桌面端到端回归于 2026-11-19 在 Linux/X11 Electron 通过：手动停止后从同一张卡恢复，已完成的 ask 只请求一次，中断的 ask 在停止前和恢复后各请求一次，两次请求各含一份原指令。动态工作流包另有 2 项脚本分析耗时预算用例在 Windows 开发机超出 10 秒上限（分析器路径与本修复无关），以 Linux 容器回归为准。

提供 Windows、macOS、Linux 桌面包与签名 Android APK，Android versionCode 为 10。macOS 使用 ad-hoc 签名，未经 Developer ID 签名或公证。Windows 未使用 Authenticode。第三方材料沿用上游已登记的 19 项缺口。

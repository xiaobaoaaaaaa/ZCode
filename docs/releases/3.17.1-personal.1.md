# ZCode Personal 3.17.1-personal.1

合入官方 v3.17.1 公开源码，保留 Personal 独立安装身份、数据目录导入、执行过程折叠、设置搜索、子代理调用级选模、引导/队列互换与侧栏独立窗口。

## 更新

- 同步官方项目管理与数据清理、个性化指令、图片标注、任务重启、统一远端配置同步、远端服务管理、插件批量更新和工作区 MCP 信任。
- 同步长会话渲染与搜索优化、工作流额度恢复续跑及 Gen UI 上下文与正文分离。
- 文件工具展开预览在运行时跟随最新输出；上滚暂停跟随，回到底部恢复。完成后不再自动滚动，历史记录从顶部开始阅读，多文件互不干扰。
- 新增同步与个性化入口沿用 Personal 数据根，避免访问官方版用户配置。
- Electron 从 41.0.3 升级至 44.7.0。

公开源码从 3.16.2 快照直接更新到 v3.17.1 标签，以上包含中间版本累计变化。官方安装包的构建提交未公开，本版基于标签 a60ba6a7 构建，不宣称与官方安装包逐字一致。

## 下载与验证

提供 Windows x64 EXE、macOS x64/ARM64 DMG 与 ZIP、Linux x64/ARM64 AppImage、DEB、RPM 和 Arch 包，共 13 个安装包。SHA256SUMS 与 release-manifest.json 记录资产哈希、源码与五个平台的原生启动结果。

默认使用 ~/.zcode-personal，可与官方版并存。自动更新关闭，请从本 fork Releases 下载。发布前验证各平台可用登录页、版本、架构及 Personal 数据隔离；这不代表所有交互、模型服务和手机远控的完整回归。

本地已通过根类型检查、Lint（83 个告警、0 错误）、162 项 CLI 针对性回归、15 项发布与隔离工程回归，以及流式文件预览 4 组真实浏览器测试。

Windows 未做 Authenticode 签名；macOS 为 ad-hoc 签名，未做 Developer ID 签名或公证。开源 Computer Use 仍使用上游占位实现，第三方声明中的 reviewRequired 不代表严格材料审计通过。

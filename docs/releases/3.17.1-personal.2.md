# ZCode Personal 3.17.1-personal.2

基于官方 3.17.1 与 Personal.1，新增内置 Codex 订阅账号，并修复执行过程与文件更改面板的显示问题。

## 更新

- 设置 → 模型设置新增 ChatGPT / Codex 订阅面板：设备码登录、退出、重新登录及多个账号管理。
- 登录后发现该账号可用的模型；添加到模型选择器后手动切换账号和模型。额度用尽不会自动切换账号。
- 请求前自动刷新令牌，凭据保存在当前 Host 的加密存储中，不读取或改写其他客户端的 auth.json。
- 展示订阅类型、额度窗口的剩余百分比和重置时间，以及服务端提供的额外额度；刷新失败保留旧值并标记过期。
- Codex 使用固定的官方 Responses 后端，支持现有文本、工具调用与上下文压缩链路。
- 修复长终端输出和部分探索/执行/文件工具分组漏出折叠的问题。
- 文件更改详情暂时不可用时显示提示和重试入口，避免展开后空白。

## 使用

在模型设置的 ChatGPT / Codex 订阅面板点击“添加账号”，在浏览器完成授权，然后“添加 / 同步模型”。聊天时从模型选择器选择相应账号的模型。

本功能用于 ZCode 内的模型调用，不包含给外部 Claude Code 改写配置或提供通用本地代理。桌面和远程连接使用各自目标 Host 的账号；在目标 Host 登录即可。退出会删除本地账号凭据及对应的自定义供应商，不撤销其他客户端的登录。

## 验证与下载

根项目及 CLI 类型检查、Lint、架构检查、64 项相关 CLI 回归、账号集成与设置页 E2E、工具折叠 E2E、文件摘要恢复和主题/窄窗口验证已通过。账号及额度联调使用合成响应；尚未完成真实订阅账号的授权与模型调用验证。真实账户的可用模型和额度由 OpenAI 返回。

提供 Windows x64 EXE、macOS x64/ARM64 DMG 与 ZIP、Linux x64/ARM64 AppImage、DEB、RPM 和 Arch 包。发布流程验证全部五个平台的原生启动与 13 个安装包，再生成 SHA256SUMS 和 release-manifest.json。

沿用 Personal 独立安装身份、数据目录和更新源，可与官方版并存。

macOS 使用 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 未使用 Authenticode。包内保留第三方声明及上游登记的材料缺口，基础许可证检查不等同于完整材料审计。

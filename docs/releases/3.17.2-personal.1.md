# ZCode Personal 3.17.2-personal.1

合入官方 3.17.2 公开源码，保留 Personal.7 的全部个人适配。

## 官方更新

- 草稿会话可在首条消息前打开插件 MCP UI；首发沿用同一会话、附件和插件上下文，完善完全访问授权、MCP 鉴权与失败提示。
- 会话恢复与重启先校验工作区归属，关闭时等待资源实际释放；改善旧 WSL 记录、子代理目录和远程草稿预热的恢复行为。
- 完善 Explore 子代理委托权限、插件 agent 权限限制和运行时提醒；自定义命令中的 shell 操作交给正常工具链执行。
- 内置浏览器通过受控协议预览本地 HTML 和相对资源；改进预览卡片、文件管理器定位入口及 Windows 未读角标。
- 同步上游依赖锁文件和平台打包修复。

## Personal 保留与合并适配

- 保留独立应用身份、数据目录、目录导入和 Personal GitHub 更新通道。
- 保留 Codex 订阅、子代理调用级选模、设置搜索、相反跟进快捷键、执行折叠、思考耗时与流式文件预览。
- 保留直接继续中断工作流、时间线浮层稳定性与独立侧栏窗口；新草稿插件上下文和本地 HTML 预览接入已有窗口路径。
- 子代理历史继续按持久父链解析所属工作区，同时采用官方的旧 WSL 解释和本地路径词法等价校验。

## 验证与限制

本地已通过根工作区、CLI 与 Electron E2E 类型检查，Lint（保留警告）、架构检查和许可证基础检查；
通过 1,188 项 CLI 回归、44 项真实浏览器回归及 18 项发布/打包工程测试。
Electron 回放通过直接继续的两项场景、完整插件市场生命周期，以及本地 HTML 的相对资源、
越界拦截、独立窗口保活、跨窗口非法导航拒绝和导航竞态。
五平台原生构建、启动及资产核验通过后公开。覆盖范围及合并规则见
[合入规格](../specs/upstream-3.17.2-personal-release.md)。

本次基于公开标签 `v3.17.2`（`a9fe401e`）；官方发布页另列的安装包构建提交
`e6b675b4` 与该同步提交不同，不声明与官方二进制完全相同。
未验证实体手机远控、真实付费模型调用或实际跨版本覆盖安装；平台原生启动检查不等同于所有功能的完整回归。

## 下载与更新

提供 Windows x64 EXE、macOS x64/ARM64 DMG 与 ZIP、Linux x64/ARM64 AppImage、DEB、RPM、Arch 包，
共 13 个安装包，附 `SHA256SUMS` 与 `release-manifest.json`。

Personal.3 或更早版本首次启用应用内更新仍需手动安装新版。
macOS 使用 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 未使用 Authenticode。

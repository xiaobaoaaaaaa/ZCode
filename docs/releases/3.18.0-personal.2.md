# ZCode Personal 3.18.0-personal.2

追加引导可以在思考阶段提前生效，并加入本轮性能与用量摘要。包含发布前工作区中已有的
性能摘要改动，继续基于官方 ZCode 3.18.0。

## 思考阶段提前接收引导

- 使用“引导”模式时，若当前请求仍在等待首个内容，或只有思考内容且尚未开始正文、工具参数和工具调用，收到追加消息后可取消该请求。
- 等旧请求完全退出后，在同一轮对话中带上追加消息继续；保留已完成的历史和工具结果，不暂停目标、不显示网络重试错误。
- 开始正文或工具后仍等待原有安全边界；普通排队模式保持等待。连续引导按序消费，Stop 优先，撤回及立即发送的预留输入不会被误消费。
- 被替换的未完成思考不进入下一次模型上下文，也不计入本轮已完成请求的性能摘要。已花费的模型计算无法撤销，不保证总耗时或 Token 用量下降。

## 本轮性能与用量

每轮可查看平均输出速度、平均首响应时间、模型请求耗时与 Token 用量，支持桌面和手机布局、
深浅主题及中英文。统计来自 CLI 的已完成主模型请求，刷新和历史恢复使用同一份事实。
不把工具执行时间算作生成速度；缺失数据不估算，并显示指标覆盖的请求数量。

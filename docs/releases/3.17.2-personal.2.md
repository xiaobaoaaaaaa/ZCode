# ZCode Personal 3.17.2-personal.2

基于 3.17.2-personal.1，为开源版本补充 Windows 电脑控制，保留既有 Personal 适配。

## 新增能力

- 启用 Computer Use 插件后，智能体可发现运行中的 Windows 应用、读取界面元素、设值、点击、输入中文、使用快捷键、拖动、滚动并截图。
- 使用系统 PowerShell、.NET UI Automation 与 Win32，不下载私有原生 Helper，也不要求额外安装 Python 或 SDK。
- 接入现有 `agent.computerUse`、node_repl 与桌面本地 Host；截图保留原始像素和坐标引用，并校验完整性。
- 控制权在 ZCode 窗口间互斥，支持 Esc 停止、运行时断连释放、陈旧坐标拒绝，以及取消时释放已按下的按键。

## 验证与限制

本地通过 Windows 专用窗口的真实 SDK 闭环、正式 bundle 的 MCP/Worker 链路、图片完整性与权限回归，
以及根/CLI 类型检查、Lint（保留既有警告）、架构检查和 Desktop 构建。
详细证据见 [实现与验收记录](../desktop/opensource-windows-computer-use.md)。

电脑控制目前仅支持 Windows；macOS/Linux 仍明确报告不可用。需要运行中的应用，
模拟输入和截图需要目标窗口处于可交互状态，不支持安全桌面、PiP 或幽灵光标。
正常 stop/Esc 后可在新会话继续；执行中的取消、超时或原生 worker 崩溃后，需要重启 ZCode 恢复控制。
未验证完整 Electron 界面至真实模型的 E2E、实体手机远控或实际跨版本覆盖安装。

## 构建与发行

沿用五平台构建和真实启动检查，全部通过后聚合草稿 Release。约定产物为 Windows x64 EXE、
macOS x64/ARM64 DMG 与 ZIP、Linux x64/ARM64 AppImage、DEB、RPM、Arch 包，
共 13 个安装包，附 `SHA256SUMS` 与 `release-manifest.json`。

macOS 使用 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 未使用 Authenticode。
保留包内第三方声明及上游登记的材料缺口，许可证基础检查不等同于完整材料审计。

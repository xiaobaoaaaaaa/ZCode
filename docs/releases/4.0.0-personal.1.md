# ZCode Personal 4.0.0-personal.1

基于 ZCode Personal 3.18.2-personal.5 合入官方 ZCode 4.0.0。

## 本版变化

- 会话输入框上方集中显示目标、待办、Git 变更与后台活动。辅助对话支持划词注释。
- 子智能体默认在后台运行，可在设置中关闭。Personal 继续支持单次调用指定模型。CLI 的 `-p` 会等待后台工作及结果触发的后续回合。
- MCP 在交互会话中后台连接，支持配置热更新。项目目录插件可在设置中逐个信任，信任后对新会话生效。
- 增加文档工具预装管理、Agent 回复语言设置、桌面崩溃重启入口及运行中退出确认。本批预装工具清单暂无 Linux 资源。
- 保留工作区助手、Codex 订阅、待发送引导撤回、每轮性能摘要、独立侧栏窗口，以及动态工作流恢复时不重复派发已交付指令的行为。

## 下载与验证

提供 Windows x64、macOS x64 与 ARM64、Linux x64 与 ARM64，以及签名 Android APK。Android versionCode 为 11。桌面用户可使用 Personal 更新通道，Android 用户可下载 APK 覆盖安装。下载校验见 `SHA256SUMS`，源码与构建记录见 `release-manifest.json` 和 `android-release.json`。

定向回归覆盖子智能体、Codex Responses、会话恢复与工作流。桌面回放通过了工作区助手、辅助对话、工作流恢复和本机 Host 的手机 Web 未读同步。SSH 队列场景、真实订阅账号与 Windows 原生电脑控制未完成实机验证。源码范围与测试记录见[合入规格](https://github.com/xiaobaoaaaaaa/ZCode/blob/v4.0.0-personal.1/docs/specs/upstream-4.0.0-personal-integration.md)。

macOS 使用 ad-hoc 签名，未使用 Developer ID 签名或公证。Windows 安装包未使用 Authenticode。第三方声明保留已有的 19 项待补材料。

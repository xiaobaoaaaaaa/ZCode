# ZCode Personal 3.18.2-personal.1

基于已发布的 3.18.1-personal.1 合入官方 3.18.2，修复登录凭据、国内 Start 权益和 Windows 更新检查。

## 更新内容

- Linux 桌面在系统密钥环不可用、凭据目录尚未绑定密钥来源时，可使用私有文件密钥完成登录保存；已有系统密钥绑定不会自动更换来源。
- 切换数据存储目录时同步登记目标路径所需的系统凭据密钥，避免复制后无法解密登录凭据。登记失败时保留原路径。
- 国内登录但未关联 BigModel 的账号可通过 ZCode 身份使用 BigModel Start 权益；设置页使用相同归属规则，不再显示错误的 Start 入口。
- Windows 更新签名检查兼容受限 PowerShell 环境和特殊字符路径，保留更新来源与完整性校验。
- 保留上一版 Personal 功能、应用身份、独立数据目录、更新通道、Codex 订阅与 SSE 适配、子代理选模、引导撤回和思考阶段引导、继续执行、独立窗口、Android 适配、问答历史答案及本轮性能摘要。

## 验证

Linux 本机根类型检查、CLI adapters 类型检查和架构检查通过。根 lint 为 0 错误、545 条
告警；改动 UI 的 7 条 Hooks 告警与上一版相同，无新增诊断。
凭据回归 42/42、发布与身份隔离回归 10/10、更新安全 smoke 24 项通过；PowerShell 等
工程回归 25 项通过、5 项因 Windows 平台限制跳过。

Linux Electron 的国内 Start 无关联账号及系统凭据跨数据目录迁移两项 E2E 通过，后者包含
冷重启读取与新凭据写入。初轮测试环境问题及重新构建后的证据见
[合入规格](https://github.com/xiaobaoaaaaaa/ZCode/blob/release/3.18.2-personal.1/docs/specs/upstream-3.18.2-personal-integration.md)。
使用合成账号控制面，未验证真实账号、模型推理、跨机远控和各系统原生安装器交互。

## 安装与更新

沿用五平台桌面与签名 Android 联合发布，Android versionCode 为 6，保持原 applicationId 与签名身份。
Android 从 Release 下载覆盖安装。`SHA256SUMS`、`release-manifest.json` 和 `android-release.json`
提供校验值、源码提交与构建验证信息。

macOS 使用 ad-hoc 签名，未经 Developer ID 签名或公证；Windows 未使用 Authenticode。
保留上游第三方声明与已登记的 19 项材料缺口，不声称严格材料审计通过。

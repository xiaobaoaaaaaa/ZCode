# ZCode Personal 3.16.2-personal.5

基于官方 ZCode 3.16.2，沿用 Personal 独立安装身份和数据目录。本版改进执行过程展示，并加入侧边标签独立窗口。

## 更新

- 执行过程保留一个折叠组，摘要按读取、编辑、终端、浏览器等类别显示次数；中英文和窄窗口均支持换行展示。
- 修复浏览器工具返回截图后，整条执行日志跳出折叠的问题。过程截图与日志一起收起，轮尾最终截图继续独立展示；展开状态不会因结果到达而重置。
- 浏览器、子代理、终端和后台命令输出标签可通过右键菜单或拖出主窗口移至独立窗口，每个标签对应一个窗口；支持拖回侧栏、按钮收回和聚焦已有窗口。
- 浏览器移出、收回及关闭独立窗口时保留同一页面实例，未提交表单、JavaScript 内存、Canvas、滚动位置和导航历史保持不变，在途操作及 Agent 浏览器操作继续执行。
- 终端保留原进程和历史输出，子代理继续接收原会话的流式内容。关闭独立窗口会把标签收回，关闭主窗口会一并关闭辅助窗口；显示位置不跨应用重启恢复。
- 独立窗口同步主题、语言和标题，权限提示与菜单跟随所属界面；浏览器过程截图及轮尾截图继续可用。文件、预览和插件等其他标签暂未接入独立窗口。

## 下载与升级

提供 Windows x64 EXE、macOS x64/ARM64 DMG 和 ZIP，以及 Linux x64/ARM64 的 AppImage、DEB、RPM、Arch 包，共 13 个安装包。文件名前缀为 `ZCode-Personal-`。

沿用 `~/.zcode-personal` 的独立数据目录，可与官方版并存。自动更新仍关闭，请从本 fork 的 Releases 下载更新。使用 `SHA256SUMS` 校验下载文件；`release-manifest.json` 记录源码提交、原生启动与数据隔离结果。

## 验证范围

本地窗口/浏览器定向单测 258 项及 8 项真实 Electron 场景通过，覆盖原生拖出与拖回、页面状态保留、在途 CDP、Agent 操作及截图、权限、终端进程与子代理输出连续性。执行折叠相关单测 239 项、8 组共享组件浏览器布局检查及桌面独立/默认回放通过。根项目和 E2E 类型检查、架构检查通过；Lint 无错误，保留 96 条既有警告。额外独立 preload/renderer TypeScript 项目仍有既有配置问题，详见仓库的侧边窗口验证记录。

桌面交互回归在 Linux X11 隔离环境执行；Windows、macOS、Wayland 的原生拖放及手机远控未新增交互实测。构建门另行验证五种原生平台的登录页、版本、架构、Personal 数据写入及官方数据保持不变，不代表所有系统版本、安装器交互、模型账号或远程功能的完整验证。

Windows 未做 Authenticode 签名；macOS 使用 ad-hoc 签名，未做 Developer ID 签名或公证。开源 Computer Use 包仍为上游占位实现。第三方声明保留上游 `reviewRequired` 材料清单，基础检查不代表严格材料审计通过，详情见 `third-party/README.md`。

# ZCode Personal 3.18.2-personal.3

本版基于 3.18.2-personal.2，集中修复辅助对话的历史显示与长对话性能。

- 新辅助对话保留模型所需的父对话上下文。主对话的压缩提示、工作时长和引导消息只在主对话显示。
- 打开辅助对话时立即显示加载提示，直到面板可交互。创建、首次订阅和首次切换模型共需完整读取子会话历史两次，原先为五次。切换辅助模型只更新该辅助对话。
- 在 Linux 桌面通过 4 项端到端回归，CLI 定向回归 709 项通过。测试覆盖 8 轮和 240 轮历史，以及有无压缩记录的组合。

提供 Windows、macOS、Linux 桌面包与签名 Android APK，Android versionCode 为 8。macOS 使用 ad-hoc 签名，未经 Developer ID 签名或公证。Windows 未使用 Authenticode。第三方材料沿用上游已登记的 19 项缺口。

# ZCode Personal 3.16.2-personal.1

首个个人构建版本，基于官方 ZCode 3.16.2（基线提交 `3c5b227649371507ddc4eb46ac5133afe6db1cab`）。
这是个人 fork 的构建，不是 Z.ai 官方发行版。

## 本版变化

- 修复 Linux 开发态因桌面包缺失 semver 版本导致更新组件初始化失败的问题。
- 补齐 `mise run dev` 的设置、业务数据和 Electron 缓存隔离。
- 建立 Windows、macOS、Linux 的原生构建、启动检查和 SHA-256 发布流程。

## 下载

- Windows x64：`.exe` 安装器。
- macOS：按 Intel `x64` 或 Apple Silicon `arm64` 选择 `.dmg` 或 `.zip`。
- Linux：按 `x64` 或 `arm64` 选择 AppImage、DEB、RPM 或 `.pkg.tar.zst`。
- `SHA256SUMS` 用于文件校验，`release-manifest.json` 记录源码提交、目标与资产摘要。

本版继续使用上游应用身份和运行时数据约定；开发任务的数据隔离不代表安装版采用独立数据目录。
开源构建的自动更新保持关闭，后续从本 fork 的 Releases 获取更新。

## 签名与验证范围

Windows 未做 Authenticode 签名；macOS 仅做 ad-hoc 签名，未做 Apple Developer ID 签名或公证，
因此可能出现系统信任提示。macOS 如因下载隔离属性阻止启动，可在确认来源和校验值后参考仓库
README 的未签名构建安装说明。

CI 验证原生构建、包结构及真实应用启动；不代表已验证所有安装器交互、模型账号与远程功能。
开源 Computer Use 包仍为上游占位实现。本版保留第三方许可原文和上游 `reviewRequired`
清单；基础声明检查不等价于严格材料审计通过，材料缺口详见 `third-party/README.md`。

# ZCode Personal 3.16.2-personal.3

首个采用独立安装身份的正式 Personal 版本，基于官方 ZCode 3.16.2，继续保留官方基线同步能力。

## 更新

- 应用名称为 **ZCode Personal**，安装包、Linux 包名、桌面协议、Electron 缓存及单实例锁与官方版分离。
- 默认数据目录改为 **`~/.zcode-personal`**（Windows 为用户主目录下 `.zcode-personal`），包括设置、会话、CLI 配置、用户技能和工作流。首次启动使用空目录，旧数据通过设置页的目录导入入口复制并切换；官方来源目录和导入前的数据保留。
- 修复项目外的“新建任务/会话”按钮误继承当前项目的问题，点击直接进入未归类草稿。项目旁新建和选择“不在项目中工作”仍可使用。
- 保留完整目录导入、连续执行活动折叠和中断后直接继续功能。

## 下载与升级

提供 Windows x64 EXE、macOS x64/ARM64 DMG 和 ZIP，以及 Linux x64/ARM64 的 AppImage、DEB、RPM、Arch 包，共 13 个安装包。文件名前缀为 `ZCode-Personal-`；`amd64`/`x86_64` 表示 x64，`aarch64` 表示 ARM64。

安装后可与官方版及旧的共享身份 Personal 版本并存，不会自动接管旧配置。需要旧数据时先正常退出旧版，从 Personal 设置页导入原 `.zcode` 目录。项目内 `.zcode` 和 `.agents` 继续沿用原有项目约定。

用 `SHA256SUMS` 校验下载文件；`release-manifest.json` 记录源码提交、五个平台的启动与数据隔离结果。自动更新继续关闭，更新从本 fork 的 Releases 下载。

## 验证范围

本地验证覆盖新建入口、导入副本、安装身份、CLI 用户路径、协议入口、真实 Electron 新建与中断继续。发布门在五种原生平台上启动真实应用，检查可用登录页、版本和架构、Personal 数据写入以及预置官方数据保持不变。该启动检查不代表所有系统版本、安装器交互、外部账号登录和远程功能的完整验证。

Windows 未做 Authenticode 签名；macOS 仅做 ad-hoc 签名，未做 Developer ID 签名或公证。官方后端登录继续使用既有轮询；系统回跳入口使用 Personal 协议，不抢占官方 `zcode://`。

# ZCode Personal 3.17.2-personal.3

基于 3.17.2-personal.2，新增可选的执行过程自动展开，保留 Windows 电脑控制与既有 Personal 适配。

## 新增能力

- 在「设置 → 通用」开启“自动展开正在执行的过程”，运行中的思考和工具过程自动展开，结束后收起。默认关闭，设置会保存。
- 手动展开或收起优先，流式追加不会覆盖选择；重新打开完成态历史时，过程仍默认收起。
- 主会话、后台唤醒轮和子代理共用规则，兼容桌面及手机布局、中英文。只自动展开外层执行过程，内层工具和思考沿用原有交互。
- 包含 personal.2 的开源 Windows 电脑控制，能力与限制见 [上一版说明](3.17.2-personal.2.md)。

## 验证范围

执行过程浏览器回归 32/32 通过；补充工具追加、手动选择跨状态更新和截图断言后，自动展开场景 6/6 通过。
隔离目录内的真实设置服务验证了默认值、保存、磁盘与重建服务读取及非法类型拒绝。
根类型、桌面 E2E 类型和架构检查通过；Lint 0 错误、84 条警告。
未执行完整 Electron 设置页到会话的 E2E、实体手机远控重连或实际跨版本覆盖安装。

## 构建与发行

沿用五平台原生构建和真实启动检查，通过后核对 13 个安装包、SHA256SUMS 和 release-manifest.json 再正式发布。
提供 Windows x64 EXE、macOS x64/ARM64 DMG 与 ZIP、Linux x64/ARM64 AppImage、DEB、RPM、Arch 包。

macOS 使用 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 未使用 Authenticode。
保留包内第三方声明及上游登记的材料缺口，许可证基础检查不等同于完整材料审计。

# ZCode Personal 3.18.2-personal.2

基于已发布的 3.18.2-personal.1，修复队列消息删除并补齐已读与代码预览操作。

## 更新内容

- 修复任务运行中已排队消息无法删除的问题。按稳定队列 ID 删除，保留编辑锁、执行占用和过期运行保护；兼容桌面实时链路与手机重连恢复链路。
- 未读任务的菜单现在提供「标记为已读」，已读任务提供「标记为未读」。覆盖侧栏各视图与会话 Header；手动清除不会打开后台任务或改变任务活动时间，新到达的未读状态由版本比对保护。
- 右侧 Git 变更与 Diff 预览现在遵循全局「长行自动换行」设置，已打开的预览会即时更新。完整文件、patch 与轻量预览保持一致，无空格长串也能在窄侧栏内换行；关闭后仍可横向滚动。
- 保留上一版 Personal 功能、独立数据目录、更新通道及 Android 适配。

## 验证

本轮新增的队列 CLI/协议回归和 Linux Electron 删除回放通过；已读菜单的桌面回放覆盖
普通列表、Header、分组、最近更新、按未读、持久化、不导航和活动时间不变。
换行浏览器回归的 390/1200px、浅色/深色四组组合通过，每组覆盖六种真实渲染路径、
即时开关、无空格长串以及刷新后的偏好保留。

根类型、架构与改动文件格式检查通过，Lint 为 0 错误、545 条既有告警；新增 Hooks
依赖无诊断。旧队列编辑 E2E 仍在进入编辑状态时失败；另一个超大事件 CLI 用例初轮超时、
单独重跑通过，未将整套测试声明为通过。另一台实体电脑、实体手机及真实远端未实测。

## 安装与更新

沿用五平台桌面与签名 Android 联合发布，Android versionCode 为 7，保持原 applicationId
与签名身份。Android 从 Release 下载覆盖安装。`SHA256SUMS`、`release-manifest.json`
和 `android-release.json` 提供校验值、源码提交与构建验证信息。

macOS 使用 ad-hoc 签名，未经 Developer ID 签名或公证；Windows 未使用 Authenticode。
保留上游第三方声明与已登记的 19 项材料缺口，不声称严格材料审计通过。

# ZCode Personal 3.17.1-personal.3

基于官方 3.17.1 与 Personal.2，补齐后台结果自动唤醒主会话时的执行过程折叠。

## 修复

- 后台子智能体或后台终端完成后，主会话可能自动继续执行，不需要用户发送补充消息。此前这类唤醒轮的独立渲染入口漏传折叠开关，导致思考和工具整段外显；Personal.2 的普通终端结果修复未覆盖此入口。
- 现在唤醒轮的 history/following 两条入口均按本轮运行状态启用共享“执行过程”分组。默认收起，手动展开后追加工具保持展开状态，重新收起隐藏过程详情。
- 后台身份标题、进度正文及需处理的交互仍在分组外；轮次完成后保留原有“已工作”历史和独立的最终回复。

本版本保留 Personal.2 的 Codex 订阅登录、多账号手动切换、令牌刷新、模型发现、额度显示，以及文件更改面板修复。安装并重启至 Personal.3 后，本次后台折叠修复才会生效。

## 验证

使用真实后台 Agent、自动完成通知和 Bash 执行的桌面受控回放：未修复版本在“后台唤醒轮未启用执行过程折叠”处失败，修复后同一用例通过。核对默认收起、展开日志、追加保持状态、再次收起、标题/正文边界及完成态历史；展开和收起截图已检查。

根类型、E2E 类型与架构检查通过；Lint 为 0 errors / 83 条既有 warnings。候选 E2E 保留 pending，未宣称获得人工晋级审核或覆盖完整手机远控恢复链路。Codex 真实订阅账号的授权与模型调用尚未实测。

## 下载与安装

提供 Windows x64 EXE、macOS x64/ARM64 DMG 与 ZIP、Linux x64/ARM64 AppImage、DEB、RPM 和 Arch 包。发布流程验证五个平台的原生启动、Personal 数据隔离及 13 个安装包，并生成 `SHA256SUMS` 和 `release-manifest.json`。

沿用 Personal 独立安装身份和数据目录，可与官方版并存。macOS 使用 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 未使用 Authenticode。包内保留第三方声明及上游登记的材料缺口，基础许可证检查不等同于完整材料审计。

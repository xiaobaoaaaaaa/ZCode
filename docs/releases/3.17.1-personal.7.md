# ZCode Personal 3.17.1-personal.7

基于 Personal.6，改进中断后的继续操作，并修复执行期间浮层意外关闭的问题。

## 改进与修复

- “继续”直接恢复当前会话的工作流程，不再发送预制用户消息，不清空草稿或改动暂挂输入队列；暂停的目标使用原有恢复命令。
- 继续操作校验当前轮次、队列与会话版本，重复点击不会启动两轮。历史恢复保留独立轮次边界；已取消的工具不会被自动重启。
- 无位移的状态刷新和流式更新不再广播人工滚动事件，失败原因浮层和选区提问菜单保持打开。真实滚动仍按原有规则关闭浮层。
- 历史大量前插后的虚拟列表位置直接同步，保留滚动跟随、历史阅读及尺寸变化时的定位行为。

## 验证与限制

- 继续操作已通过 283 项 CLI 回归及 Electron 模型回放，覆盖无新增用户消息、重复点击、原会话和暂挂队列保留。
- 浮层与滚动的 20 项真实共享 UI 浏览器验收通过，覆盖桌面/手机布局、中英文、深浅主题、真实滚动及大量历史前插；尺寸变化与历史补齐通过；重新构建后的继续/长会话滚动 Electron 回放 3/3 通过。
- 执行根类型检查、Lint、架构及发布门禁；五平台构建和安装包启动验证全部通过后公开。
- 手机布局验收不等价于实体手机远控；未验证真实付费模型调用、网络 ACK 丢失的完整链路或真实跨版本覆盖安装。

## 下载与更新

提供 Windows x64 EXE、macOS x64/ARM64 DMG 与 ZIP、Linux x64/ARM64 AppImage、DEB、RPM、Arch 包，共 13 个安装包，附 SHA256SUMS 与 release-manifest.json。

Personal.3 或更早版本首次启用应用内更新仍需手动安装新版。保留 ZCode Personal 独立应用身份与数据目录。

macOS 为 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 未使用 Authenticode。保留包内第三方声明和上游登记的材料缺口，基础许可证检查不等同于完整材料审计。

# ZCode Personal 3.17.1-personal.5

基于官方 3.17.1 与 Personal.4，修复 ChatGPT / Codex 账号模型同步，并统一订阅账号卡片样式。包含 Personal.4 的子代理历史、执行过程折叠、手机远控版本映射与应用内更新功能。

## Codex 修复与界面

- 修复登录成功后点击“添加 / 同步模型”失败：账号接入传入了供应商创建接口禁止的 `initialConfig.group`；现在由配置服务统一设置个人分组。首次创建、重复同步与新增模型补齐不会覆盖已有模型配置。
- ChatGPT / Codex 进入与 BigModel、Start Plan 相同的供应商导航和详情容器，复用官方套餐卡片外壳。额度改为剩余百分比和进度条，重新登录与退出收进更多菜单，完整时间和 workspace 身份放在提示中。
- 展示账号发现的可用模型目录，保留显式同步操作；该目录不冒充本地已启用模型状态。同步失败提供单独重试提示，成功反馈限定对应账号。
- 额度只显示接口返回的有效窗口，不固定展示“五小时”卡片。没有窗口时显示额度未知，不根据 Pro 套餐名称推断不限量。

## 验证与限制

- 定向运行时/浏览器验收覆盖首次与重复同步、保留模型禁用状态和供应商配置、新模型补齐；桌面/手机宽度、中英文、深浅主题；未知额度、额外 credits、空账号和多账号反馈隔离。
- 发布流程执行类型、Lint、许可证和发布工具检查；五个原生平台打包后进行真实启动与独立数据目录验证，并核对安装包校验值。
- 账号、额度及授权验收使用合成数据；未验证真实付费模型调用、实体手机公网远控或真实跨版本覆盖安装。完整 Electron Codex 交互用例本轮未重跑。

## 下载与更新

提供 Windows x64 EXE、macOS x64/ARM64 DMG 与 ZIP、Linux x64/ARM64 AppImage、DEB、RPM、Arch 包，共 13 个安装包，附 `SHA256SUMS` 与 `release-manifest.json`。

Personal.3 或更早版本首次启用应用内更新仍需手动安装新版。草稿不进入应用更新源；公开后按稳定/预览通道及平台安装能力检查更新。保留 ZCode Personal 独立应用身份与数据目录。

macOS 为 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 未使用 Authenticode。保留包内第三方声明和上游登记的材料缺口，基础许可证检查不等同于完整材料审计。

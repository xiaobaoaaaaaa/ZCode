# ZCode Personal 3.17.1-personal.6

基于 Personal.5，修复思考耗时在折叠、重新展开及恢复历史后重置的问题，保留之前的 Codex 账户、模型同步、执行过程折叠和应用内更新功能。

## 修复

- 运行中的思考使用消息原始开始时间，首次延迟展开或反复折叠后仍显示累计耗时。
- CLI 在思考结束、取消、错误、流尾丢弃和模型降级时保存耗时；历史重挂载与事件重放复用同一结果。
- 迟到的结束事件不会改写已结束行；不同思考段独立计时，旧快照缺少耗时时不伪造时长。

## 验证与限制

- CLI 投影回归覆盖 248 项；浏览器验收覆盖历史折叠及思考计时、桌面/手机布局、中英文和深浅主题。
- 执行根类型检查、bootstrap 类型检查、Lint、架构及发布门禁。五平台构建和安装包启动验证通过后公开。
- 浏览器手机布局不等价于实体手机远控验证；未验证真实跨版本覆盖安装或真实付费模型调用。

## 下载与更新

提供 Windows x64 EXE、macOS x64/ARM64 DMG 与 ZIP、Linux x64/ARM64 AppImage、DEB、RPM、Arch 包，共 13 个安装包，附 SHA256SUMS 与 release-manifest.json。

Personal.3 或更早版本首次启用应用内更新仍需手动安装新版。保留 ZCode Personal 独立应用身份与数据目录。

macOS 为 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 未使用 Authenticode。保留包内第三方声明和上游登记的材料缺口，基础许可证检查不等同于完整材料审计。

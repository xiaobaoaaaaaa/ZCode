# ZCode Personal 3.16.2-personal.2

首个正式个人版，基于官方 ZCode 3.16.2（基线提交 `3c5b227649371507ddc4eb46ac5133afe6db1cab`）。
这是个人 fork 的发行版，后续继续在官方基线上维护个人适配。

## 本版功能

- **中断后直接继续**：停止完成且输入框为空时，右下角显示“继续”按钮。点击沿用当前会话和已有上下文继续任务；输入新内容时仍正常发送。快速连点不会重复提交，暂停队列保持原顺序和内容；暂停的 Goal 复用原有恢复命令。
- **连续执行过程折叠**：执行期间连续的思考、工具调用、文件读写汇总为可展开的执行过程。展开后保留原有工具详情与文件 Diff，流式追加不会重置手动展开状态。
- **从指定 ZCode 目录导入**：设置 → 通用 → 从 ZCode 目录导入。完整复制后切换使用独立副本，保留来源目录和当前数据。支持选择 `.zcode` 目录或其上级目录，完成校验后冷重启恢复历史。
- 包含首个预发布版的开发环境隔离和跨平台原生构建、启动检查、SHA-256 校验流程。

## 下载与校验

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| Windows | x64 | EXE |
| macOS | Intel x64、Apple Silicon ARM64 | DMG、ZIP |
| Linux | x64、ARM64 | AppImage、DEB、RPM、Arch `.pkg.tar.zst` |

共 13 个安装包。文件名中的 `x86_64`、`amd64` 表示 x64，`aarch64` 表示 ARM64。
使用 `SHA256SUMS` 校验下载文件；`release-manifest.json` 记录源码提交、各目标启动检查与资产摘要。

升级前正常退出旧版。安装版继续使用上游应用身份和默认数据目录；如需迁移数据，可使用本版的目录导入入口。
开源构建的自动更新保持关闭，后续更新请从本 fork 的 Releases 下载。

## 验证与已知限制

本版功能完成定向单测、真实 Electron 停止/继续与队列验证、深浅主题和中英文检查。
发布流程在 Windows x64、macOS x64/ARM64、Linux x64/ARM64 原生 runner 上构建并启动真实应用，
核验版本、架构、可用登录页、包结构和 SHA-256。启动检查不代表所有系统版本、安装器交互、模型账号与远程功能的完整验证。

Windows 未做 Authenticode 签名；macOS 仅做 ad-hoc 签名，未做 Apple Developer ID 签名或公证，可能出现系统信任提示。
macOS 如因下载隔离属性阻止启动，请先确认来源和校验值，再参考仓库 README 的未签名构建安装说明。

开源 Computer Use 包仍为上游占位实现。包内保留第三方许可原文与上游 `reviewRequired` 清单；
基础声明检查不等价于严格材料审计通过，材料缺口详见 `third-party/README.md`。

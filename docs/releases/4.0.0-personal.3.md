# ZCode Personal 4.0.0-personal.3

- 编写长消息时，点击输入框右上角的「展开输入框」，可以用半屏高度编辑。再次点击即可收起，正文、光标和选区都会保留。
- 开启输入预测后，一轮回答完成时，空白输入框可以显示与回答相关的候选追问。按 Tab 将追问填入草稿，可以继续编辑，确认后再发送。

提供 Windows、macOS、Linux 桌面安装包和签名 Android APK。Android versionCode 为 13，下载校验值见 `SHA256SUMS`。

macOS 使用 ad-hoc 签名，未经 Developer ID 签名或公证。Windows 安装包未使用 Authenticode。第三方声明保留已有的 19 项待补材料。

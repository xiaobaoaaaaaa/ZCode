# ZCode Personal 3.18.1-personal.1

同步官方 ZCode 3.18.1 源码，并将本轮性能摘要运行态改为带已完成请求数的样式。

## 官方更新与 Personal 功能

- 合入官方 3.18.1：Windows 安装/更新链路加固（旧安装目录残留进程按完整映像路径句柄收口、备份改为尽力语义并按有无备份区分提示）、麦克风权限引导浮层与 macOS 重授权、CLI 内存诊断、ZAI 国内渠道 OAuth 修复、macOS 字体平滑、队列摘要流式渲染与 reasoning 流式自动折叠、交互来源徽标等。
- 同一功能或修复的不同实现以官方为准：对话列最小宽度采用官方规则（web-remote shell 0px、桌面 360px）。
- 保留 Codex 订阅与 SSE 适配、子代理按次选模、待引导撤回、无预设用户消息的继续执行、独立侧栏窗口、Android 平板布局和设备偏好、Personal 身份与发布通道、AskUserQuestion 历史答案修复与本轮性能摘要。

## 本轮性能摘要计数

运行中摘要由「本轮已完成请求」改为「本轮（已完成 N 请求）」（英文 `This turn (N completed)`），
一眼可见统计样本量；完成态样式不变，详情浮层继续提供完整指标。规则见
[本轮性能摘要](../ui/turn-performance-summary.md)。

# 工作区助手研究预览

在 ZCode Personal 桌面端打开本地工作区，点击侧栏的「工作区助手」。你可以在一处讨论多个事项，让它创建普通任务、继续已有任务，或在指代不清时列出候选。点击「继续此任务」可直接指定目标。需要审批、回答或手动接手时，打开卡片对应的原任务。退出应用后执行停止，重新打开可查看历史并续接。

每个事项拥有独立的会话上下文，同一工作区的任务共享文件。自然语言归属可能判断有误，涉及多个相似事项时可显式选择目标。基础模型仍沿用用户配置。

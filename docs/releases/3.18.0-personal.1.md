# ZCode Personal 3.18.0-personal.1

同步官方 ZCode 3.18.0 源码，并包含此前未发布的 AskUserQuestion 历史答案显示修复。

## 官方更新与 Personal 功能

- 合入官方新版会话、Worktree、扩展、语音和模型设置相关实现。
- 设置搜索、连续摘要分组、队列编辑和发送快捷键采用官方实现。Personal 独有设置接入官方搜索；可选的运行过程自动展开继续可用，手动开合优先。
- 保留 Codex 订阅与 SSE 适配、子代理按次选模、待引导撤回、无预设用户消息的继续执行、独立侧栏窗口、Android 平板布局和设备偏好。
- 待引导撤回兼容官方队列编辑锁及绑定代次，切换会话再返回时不会把旧确认恢复进新草稿。
- 保留独立应用身份、数据目录和更新通道，可与官方版并存。

## 问答历史答案修复

修复部分 AskUserQuestion 已完成记录在历史视图中未显示用户答案的问题。保留原始记录的
读取兼容路径，并通过桌面/手机宽度、深浅主题的 8 项浏览器回归。此前报告设备的原始记录
不可得，因此不把其具体触发原因作为已确认结论。

## 验证

根与 CLI 类型检查、架构和提交门禁通过。CLI 定向回归 642 项通过、1 项跳过；
浏览器回归 108 项通过；Linux Electron 的引导撤回、继续执行和独立子代理窗口共 4 项通过。
Android 设备偏好的 4 个语言主题组合与平板布局的 36 项观察通过。

根 Lint 为 0 错误、545 条警告。工程测试选择器将跨版本合并选为全部 169 个规格，按仓库
现有规则跳过全套；另行执行了 Personal 发布、隔离与 Android 的 11 项定向工程回归。
未将真实模型账号、跨机远控及所有系统的安装器交互列为已验证范围。

## 安装与更新

提供 Windows x64、macOS x64/ARM64、Linux x64/ARM64 共 13 个桌面安装包，以及
同签名 Android APK（versionCode 3）。Android 从 Release 下载覆盖安装。
发布流程核对五平台真实启动、Personal 数据隔离、Android 签名及全部远端资产摘要后公开。

macOS 使用 ad-hoc 签名，未经 Developer ID 签名或公证；Windows 未使用 Authenticode。
保留上游第三方声明及已登记材料缺口，不声称严格材料审计通过。`SHA256SUMS`、
`release-manifest.json` 和 `android-release.json` 提供校验值、源码提交及构建验证信息。

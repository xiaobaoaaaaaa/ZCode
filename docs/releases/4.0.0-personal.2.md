# ZCode Personal 4.0.0-personal.2

本版替代 4.0.0-personal.1。

- 从桌面正式版撤回工作区助手。助手创建的普通任务仍可从任务列表打开。
- 修复 Codex 账号刷新使用旧目录版本的问题。账号有权限时，刷新可发现 GPT-6.2 Sol 和 Astra，再点「同步模型」即可添加到模型选择器。

Fedora 桌面回放确认助手入口已撤回，普通任务重启后可重新打开。已登录账号的真实模型目录返回 Sol 和 Astra，隔离同步验证覆盖模型添加与去重。

提供 Windows、macOS、Linux 桌面包和签名 Android APK，Android versionCode 为 12。下载校验见 `SHA256SUMS`。

macOS 使用 ad-hoc 签名，未经 Developer ID 签名或公证。Windows 安装包未使用 Authenticode。第三方声明保留已有的 19 项待补材料。

# ZCode Personal 3.17.2-personal.5

基于 3.17.2-personal.4，新增待引导撤回并修复 Codex 订阅模型的非流式响应转换。

## 待引导消息撤回

等待进入上下文的引导消息旁新增“撤回”。成功后恢复到发起端输入框，方便修改重发；
输入框已有草稿或正在处理输入时阻止撤回，避免覆盖。当前模型执行继续运行。

CLI 在写入取消状态前占用目标输入，防止同一条引导同时被消费；消费开始后拒绝撤回。
同时修复异步写库期间数组位置变化可能误删邻项，以及旧投影误取消已消费消息的竞态。
沿用原有队列命令、权威状态和跨会话隔离，不新增另一套队列。

## Codex SSE 转换修复

修复 WebFetch 内容提取、compact 等非流式调用收到 Codex SSE 时的 JSON 解析失败。
原先只有 Content-Type 精确符合条件才转换；实际响应缺少或使用不同 MIME 头时会绕过转换。
现在固定 Codex 订阅端点按调用方的原始流式意图决定转换，消费 SSE 终态后返回标准 JSON，
并保证取消过程中释放 reader。普通 API-key provider 和原始流式调用保持原路径。

失败请求正文与同会话缺头响应支持此定位，失败调用自身未保留响应头；相同缺头场景
已通过真实 AI SDK 的合成响应回归复现并修复，未进行真实账号联网复测。

7 条已接纳上游行数诊断，均 0 错误。手机远控/双端重连的本功能交互尚未实测。

## 安装与更新

提供 Windows x64、macOS x64/ARM64、Linux x64/ARM64 共 13 个桌面安装包，以及
同签名 Android APK（versionCode 2）。Android 的共享前端随 APK 更新，从 Release 下载覆盖安装。
发布流程检查五个平台实际启动、Android 签名和版本，并核对全部安装包及元数据摘要后公开。

macOS 为 ad-hoc 签名，未经 Developer ID 签名或公证；Windows 未使用 Authenticode。
保留既有第三方声明及已登记材料缺口。`SHA256SUMS`、`release-manifest.json` 和
`android-release.json` 提供校验值、源码提交及构建验证信息。

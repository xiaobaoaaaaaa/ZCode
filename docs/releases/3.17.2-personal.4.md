# ZCode Personal 3.17.2-personal.4

新增 Android 多电脑远控 App，复用桌面 Host 与共享 UI。支持电脑列表、最近电脑及项目/会话恢复、扫码/链接入口、本机隐藏电脑、文件选择和错误重试。

平板宽屏使用桌面同款侧栏、会话与文件面板；支持横竖屏、窄窗口和真实输入法，修复高度变化误收面板及分屏触发页面重载。未提交草稿沿用既有隔离与持久化规则。

## 验证

浏览器平板36/36、Android平板40/40检查通过，Android壳6/6回归通过，中英文与亮暗主题已验证。使用受控会话数据；未验证真实双电脑、公网OAuth、相机扫码与模型发送。类型与架构检查通过，Lint 0错误、84条已有警告。

## 安装与更新

桌面提供Windows x64、macOS x64/ARM64及Linux x64/ARM64安装包，沿用Personal更新。Android提供Android 7.0及以上的正式签名APK，应用ID为io.github.xiaobaoaaaaaa.zcode；首版从Release下载，后续同签名APK可覆盖安装。开发debug版使用不同应用ID，正式版需重新登录。

Android前端随APK打包，更新共享界面需要更新APK。签名证书摘要、版本号与源码提交记录于android-release.json；所有安装包提供SHA256SUMS。

macOS为ad-hoc签名，未经Developer ID签名或公证；Windows未使用Authenticode。保留既有第三方声明及已登记材料缺口。

# ZCode Personal 3.16.2-personal.4

基于官方 ZCode 3.16.2，包含上一版 Personal 的独立安装身份、数据目录导入、活动折叠与中断继续功能。

## 更新

- 主智能体调用子代理时可为本次调用指定模型；不指定时沿用既有配置与继承规则。非法或不可用模型会在启动前返回诊断，子代理续跑保持已经选定的模型。
- 设置页新增全局搜索，支持中英文设置名称和说明、键盘选择、分区跳转以及具体设置项的定位高亮；只显示当前平台可用的候选。
- 任务运行时，Enter 沿用设置中的“引导”或“队列”，Ctrl+Enter（macOS 为 Cmd+Enter）采用相反方式；组合键不修改默认设置。“队列”模式下的组合键不再抢占当前执行。
- 修复桌面启动已完成但根节点透明动画仍等待绘制时无法点击的问题。应用 ready 后立即可见，保留启动遮罩的淡出效果。

## 下载与升级

提供 Windows x64 EXE、macOS x64/ARM64 DMG 和 ZIP，以及 Linux x64/ARM64 的 AppImage、DEB、RPM、Arch 包，共 13 个安装包。文件名前缀为 `ZCode-Personal-`。

沿用 `~/.zcode-personal` 的独立数据目录，可与官方版并存。自动更新仍关闭，请从本 fork 的 Releases 下载更新。使用 `SHA256SUMS` 校验下载文件；`release-manifest.json` 记录源码提交、原生启动与数据隔离结果。
